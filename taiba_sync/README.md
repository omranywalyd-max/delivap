# sync_taiba_images — مزامنة صور المنتجات من taibaoline إلى Deliv

> هذا الدليل يُقرأ من إنسان **ومن AI** (مساعد كود). يشرح المشروع، وكيف يشتغل السكربت، وكيف تتعامل معه بأمان.

---

## 1. الهدف

متجر Deliv (`delivap.com`) وموقع **taibaoline.com** يبيعون نفس المنتجات (مواد غذائية أساساً).
عندنا في Deliv **865 منتج**، كثير منها **بلا صورة** أو بصورتها الحالية ضعيفة.
موقع taibaoline عنده **+2000 منتج** (في قسم المواد الغذائية وحدها) وصورهم **بأغلبها بخلفية مشالة** (شفافة).

السكربت `sync_taiba_images.py`:
1. يجيب منتجات taibaoline من الـ API الرسمي.
2. يجيب منتجاتنا من API ديليف.
3. **يطابق المنتجات بالاسم + الحجم** (المقاس).
4. ياخذ صورة المنتج من taibaoline (يفضّل الشفافة، وإن ما لقاش ياخذ أي صورة).
5. يرفع الصورة لسيرفر ديليف ويحدّث المنتج تلقائياً.

## 4. طريقة عمل المطابقة (اسم + حجم)

### 4.1 التطبيع (Normalization)
- تحويل لأحرف صغيرة، إزالة التشكيل والـ accents الفرنسية.
- توحيد الحروف العربية: `أ/إ/آ → ا`، `ة → ه`، `ى → ي`، `ؤ → و`، `ئ → ي`، `ء → حذف`.
- تجزئة النص إلى كلمات (tokens) وحذف كلمات عامة بلا قيمة (`من، في، le, de, et, ...`).

### 4.2 الحجم (Size)
يُستخرج من الاسم **ومن الوصف العربي** ومن حقل `capacite` عندنا:
- `لتر/litre/L/l` و `مل/ml` و `cl` → حجم بالملليلتر.
- `كغ/kg` و `غ/g/gr` → وزن بالغرام.
- `capacite` تاعنا إن كانت رقم ≤ 10 (مثل `0.5`) نعتبرها لتر.
- `40/5` (علب مشتركة) ما نعتبرهاش حجم.

القاعدة: **الحجم لازم يطابق** (نفس النوع vol/wt + فرق ≤ 2%). مثال:
- عندنا "حليب كانديا" (capacite `0.5`) = 500ml
- في طيبة "Candia Lait Sans Lactose 50CL" = 500ml ✅ تطابق
- "Candia Lait Entier 1 Litre" = 1000ml ❌ لا تطابق

### 4.3 الاسم
- **كلمات وحدات الحجم** (`لتر، مل، كغ، غ، litre, kg ...`) و**الكلمات الضعيفة** (`بدون، عادي، برومو، رمضان، كرطونة، علبة، زجاج، بلاستيك ...`)
  **تُحذف من الاسم** — هي سبب مطابقات خاطئة سابقة:
  - "افري1 لتر" كانت تطابق "حليب أوبي 1 لتر" بفضل كلمة "لتر" المشتركة (الصحيح: Ifri 1L).
  - "مقرون بدون غلوتين" كانت تطابق "خميرة المردجان" لأن منتج الخميرة **عنده وسم "بدون غلوتين"**!
- درجة الاسم = `max(تغطية الكلمات المشتركة, نسبة التشابه SequenceMatcher)`.
نقارن اسمنا مع (اسم طيبة + الوصف العربي + الوسوم tags) لأن طيبة تعطينا الاسم بالعربية أيضاً
(مثال: `Candia Lait` ↔ وصفه العربي "كانديا حليب"). هذا يحل مشكلة الترجمة الصوتية (transliteration).

### 4.4 شروط القبول
- إذا كان **عندنا** معلومات حجم → **لازم** الحجم يطابق، وإلا نرفض المنتج نهائياً.
- إذا ما كانش عندنا حجم → نعتمد على الاسم فقط (ثقة أقل).
- **التغطية (coverage)** تُحسب على **الكلمات المميزة فقط** (تظهر في ≤150 منتج طيبة).
- **BRAND_GAP**: إذا كان في اسمنا كلمة مميزة ما لقيناهاش في منتج طيبة (مثل "الجمل" مع "خيمة") → يتحول للمراجعة ولا يتطبّق تلقائياً.

### 4.5 مستويات الثقة (Confidence)
| المستوى | الشرط |
|---------|-------|
| **HIGH** | الحجم يطابق + **التغطية ≥ 0.55** (لا تُقبل HIGH من التشابه اللفظي وحده) |
| **MEDIUM** | الحجم يطابق + درجة الاسم ≥ 0.35، أو (بلا حجم عندنا + اسم ≥ 0.65) |
| **LOW** | الباقي (يُعرض في التقرير فقط، ما يتطبّقش) |

## 5. اختيار الصورة

- نفضّل الصور **الشفافة**: اسم الملف يحوي `Remove-bg.ai` / `SnapBG.ai` / `transparent` أو ينتهي بـ `.png`.
- إن ما لقينا صورة شفافة → ناخذ أول صورة عادية (JPG/webp) — هذا مقبول.
- نحمّل الصورة من الرابط المباشر `https://www.taibaoline.com/wp-content/uploads/...`
  (نشيل `i0.wp.com` والـ query parameters باش نحصل على الصورة الأصلية).

## 6. كيف تشغّل

> المتطلب الوحيد: **Python 3** (مثبّت عندنا — 3.12.10). لا يحتاج أي مكتبات خارجية (`requests` غير مطلوب — استعملنا `urllib` فقط).

### تجربة بدون تغيير (Dry-run) — الافتراضي
```bash
cd C:\flutter_application_1\taiba_sync
python sync_taiba_images.py
```
هذا **ما يغيّر شيئاً** — فقط يجلب ويطابق وينتج تقريراً.

### تجربة على قسم الغذاء فقط
```bash
python sync_taiba_images.py --taiba-category 3601
```

### تجربة على عدد قليل (للتجربة السريعة)
```bash
python sync_taiba_images.py --limit-our 20
```

### التطبيق الفعلي (يعدّل المنتجات في المتجر الحي!)
```bash
python sync_taiba_images.py --apply          # يطبّق HIGH فقط (والمنتجات بلا صورة)
python sync_taiba_images.py --apply --overwrite   # يحدّث حتى المنتجات التي لها صورة أصلاً
python sync_taiba_images.py --apply-all      # يطبّق كل المطابقات (HIGH + MEDIUM + LOW)
python sync_taiba_images.py --apply --only-missing   # للمنتجات التي بلا صورة فقط (الافتراضي الآن)
```

> **افتراضياً** السكربت يتعامل فقط مع المنتجات **بلا صورة** حتى لا يمسح صوراً جيدة.
> استعمل `--overwrite` إذا تريد فعلاً تغيير الصور الموجودة.

## 7. المخرجات

في مجلد `output\` يُنشأ تقريران باسم بوقت التشغيل:
- `report_matches_YYYYMMDD-HHMMSS.csv` — جدول كامل (يفتح في Excel).
- `report_matches_YYYYMMDD-HHMMSS.md` — نفس الجدول بصيغة Markdown.

الأعمدة: `our_id, our_name, our_price, our_capacite, our_size, taiba_id, taiba_name, taiba_price, taiba_size, name_score, coverage, fuzzy, size_match, confidence, flag, image_url, image_transparent, action, old_image, new_image, error`.

قيم `action`:
- `WOULD_APPLY` / `WOULD_REVIEW` — في وضع التجربة.
- `UPDATED` — تم تغيير الصورة بنجاح.
- `REVIEW_*` — مطابقة ممكنة لكن فيها `BRAND_GAP`/`COMMON_ONLY`/`DUP_SOURCE` — **راجعها يدوياً** قبل أي تطبيق.
- `SKIP_LOW_CONFIDENCE` — ثقة أقل من المطلوب.
- `NO_IMAGE_ON_TAIBA` — طيبة ما عندوش صورة لهذا المنتج.
- `ERROR` — فشل الرفع أو التعديل (السبب في عمود `error`).

## 9. ملاحظات وأخطار

1. **التعديل على المتجر الحي**: دائماً شغّل `--apply` بعد ما تراجع التقرير. يفضل تبدأ بـ `--limit-our 20`.
2. **الترجمة الصوتية**: أسماءنا عربية (مثل "حليب كانديا") وأسماءهم فرنسية + وصف عربي. المطابقة تعتمد على الوصف العربي والوسوم. قد تطلع مطابقات خاطئة → راجع التقرير.
3. **العلامات/الوسوم خدّاعة**: منتجات مثل الخميرة تحمل وسم "بدون غلوتين" فتتعارك مع "مقرون بدون غلوتين" — عالجناها (كلمة "بدون" محذوفة + BRAND_GAP → مراجعة) لكن لا تثق بالوسوم وحدها.
4. **عدد كبير من الطلبات**: جلب كل طيبة = 39 طلباً. مدة مقبولة (كل صفحة 100 منتج).
5. **الأمان**: الـ token الأدمن ينتهي بعد 24 ساعة — السكربت يسجل الدخول كل مرة بنفسو.
6. **لا ترفع هذا المجلد للـ GitHub** لأنه يحتوي كلمة سر.
7. إذا بدلنا `STORE_ID` أو `ADMIN_*` — عدّل في `CONFIG` في أول السكربت.
8. **الاسترجاع**: للتقرير المطبّق استعمل `python sync_taiba_images.py --revert-report output/report_matches_XXXX.csv` ليعيد كل `old_image`.
